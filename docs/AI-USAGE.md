# AI assistance disclosure

This assignment used ChatGPT (OpenAI) as a drafting and review assistant during the final documentation pass. It was used to inspect the supplied repository and assignment brief, draft and organize documentation (README, architecture notes, ADRs, engineering notes, and evidence checklist), and identify mismatches or missing submission artifacts.

The team remains responsible for validating every technical statement against the implementation and the live cluster. In particular, AI assistance did not generate real cluster measurements, recall@5 scores, indexer peak-memory readings, screenshots, GitHub Actions run links, or Docker Hub publication evidence. Those must come from the team's own execution. The team should review, edit, and understand the generated documentation before committing it, and should update this disclosure if other AI tools or assistants were used earlier in the project.
