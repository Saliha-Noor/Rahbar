# AI assistance disclosure

This assignment used ChatGPT (OpenAI) as a drafting and review assistant during the final documentation pass. It was used to inspect the supplied repository and assignment brief, draft and organize documentation (README, architecture notes, ADRs, engineering notes, and evidence checklist), and identify mismatches or missing submission artifacts.

The team remains responsible for validating every technical statement against the implementation and the live cluster. In particular, AI assistance did not generate real cluster measurements, recall@5 scores, indexer peak-memory readings, screenshots, GitHub Actions run links, or Docker Hub publication evidence. Those must come from the team's own execution. The team should review, edit, and understand the generated documentation before committing it, and should update this disclosure if other AI tools or assistants were used earlier in the project.

## Use of Claude AI

Claude AI was used as an assistance tool during the development of this assignment, particularly for **Division C commands, code implementation, and debugging**. It helped us understand and execute the required terminal commands, prepare and review configuration files, and troubleshoot errors encountered during the setup and deployment process.

We also used Claude to assist with understanding Docker and Kubernetes commands, reviewing YAML configurations, identifying potential issues in the code, and suggesting possible solutions when errors occurred. Additionally, it helped explain command outputs and improve our understanding of different project components.

However, AI assistance was used only as a supporting resource. We reviewed the suggested commands and code, applied them to our project environment, and performed the implementation and testing ourselves. The final decisions, verification, and responsibility for the submitted work remained with our team.
